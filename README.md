# Study OS v19

개인용 원문 근거 학습도구 MVP.

## v19 핵심
- 수업 방식대로 `로컬 → GitHub → Vercel` 배포 흐름에 맞춘 배포 패키지 정리
- `.gitignore` 추가: `.env`, `.vercel`, 로그 등 민감/로컬 파일 커밋 방지
- `.env.example` 추가: 변수 이름만 공유하고 실제 키는 저장하지 않음
- `DEPLOY.md` 추가: 기존 Coway 프로젝트를 건드리지 않는 별도 Study OS 배포 순서
- v16 학습 기능 그대로 유지

## 학습 원칙
- 파일 기반 학습도구는 SOURCE ONLY
- 카드/OX/빈칸/객관식/요약은 한 번 생성 후 잠금·재사용
- AI 학습은 별도 버튼으로만 호출
- API 키는 서버 환경변수에서만 사용

## 배포
새 GitHub 비공개 저장소 `study-os`를 만든 뒤 이 프로젝트만 업로드하고, Vercel에서 해당 저장소를 새 프로젝트로 Import합니다.

## v19 실제 교재 인식 테스트
- `1차.pdf`, `1차(숫자).pdf`: 150p 스캔형 1차 기초입문서 업로드본으로 인식
- `2차.pdf`, `2차(숫자).pdf`: 150p 스캔형 2차 기초입문서 업로드본으로 인식
- `공인중개사 1차 기출지문*.pdf`: 45p 빈출지문 정리노트로 인식
- 2차 업로드본은 실제 150페이지 안에 들어있는 `SUBJECT 1 공인중개사법령 및 중개실무` 단원만 프리셋으로 생성
- 목차에 보이지만 업로드본에 없는 뒤쪽 과목은 진도 단원으로 만들지 않음


## CH01 실교재 검증 세트
- `1차.pdf` / `1차(1).pdf` 150p 스캔본을 등록하면 `PDF p.11~13 / 교재 p.23~25` 범위에 스타터 학습세트를 자동 설치합니다.
- 구성: 카드 9, OX 7, 빈칸 6, 객관식 5, 핵심요약 1.
- 해당 세트는 원문 전체를 복제하지 않고 페이지에서 확인되는 핵심 학습 포인트만 SOURCE ONLY로 구조화했습니다.
- 설치 즉시 각 도구가 잠금되어 반복학습 시 AI를 재호출하지 않습니다.
